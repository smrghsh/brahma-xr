# Brahma XR Server

A powerful WebSocket-based backend for real-time multiplayer VR experiences.

## 🚀 Features

- Secure HTTPS and WebSocket communication
- Real-time avatar data (position, controllers, color)
- Unique username and color assignment
- Active user tracking
- Simulation time control and broadcast
