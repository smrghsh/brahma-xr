## BrahmaServer Options

| Option   | Type   | Default                | Description                          |
|----------|--------|------------------------|--------------------------------------|
| `port`   | number | `8080`                 | Port number for the HTTPS server     |
| `certPath` | string | `"../cert/cert.pem"` | Path to the SSL certificate          |
| `keyPath`  | string | `"../cert/key.pem"`  | Path to the SSL private key          |
